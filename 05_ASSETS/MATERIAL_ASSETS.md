# Sanyo Yusoki Vietnam — Material Assets

## Purpose

Centralize approved visual material references.

## Material Categories

- Stainless steel
- Glass
- Wood
- Stone
- Tile
- Fabric
- Painted surfaces
- Lighting materials
- Cabin finishes

## Material Metadata

Each material should define:

- Material ID
- Name
- Surface type
- Texture
- Reflectivity
- Roughness
- Typical usage
- Approved reference

## Rules

Material appearance should remain consistent between shots.

Do not randomly change materials between scenes.

## Naming Convention

MAT_[CATEGORY]_[NAME]_V[VERSION]

Example:

MAT_STAINLESS_BRUSHED_V01
