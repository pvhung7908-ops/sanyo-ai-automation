# Sanyo Yusoki Vietnam — Cabin Assets

## Purpose

Maintain consistent cabin appearance across AI-generated scenes.

## Asset Types

- Cabin exterior
- Cabin interior
- Ceiling
- Floor
- Wall panels
- Handrail
- Control panel
- Lighting
- Door
- Materials

## Consistency Rules

The following must remain stable when an approved cabin is used:

- Proportions
- Door position
- Door geometry
- Control panel position
- Material appearance
- Lighting concept
- Interior layout
- Human scale

## Naming Convention

CABIN_[MODEL]_[VIEW]_[TYPE]_V[VERSION]

Example:

CABIN_SMART_INTERIOR_FRONT_V01
