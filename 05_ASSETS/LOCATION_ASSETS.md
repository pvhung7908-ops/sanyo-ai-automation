# Sanyo Yusoki Vietnam — Location Assets

## Purpose

Define reusable locations for content and video production.

## Location Types

- Hanoi residential street
- Vietnamese tube house
- Family home
- Sanyo Yusoki showroom
- Construction site
- Renovation site
- Urban neighborhood
- Villa
- Apartment

## Location Metadata

Each location should define:

- Location ID
- City
- Environment
- Architecture
- Lighting
- Time of day
- Reference images
- Usage restrictions

## Naming Convention

LOC_[CITY]_[TYPE]_[ID]_V[VERSION]

Example:

LOC_HANOI_TUBEHOUSE_01_V01
