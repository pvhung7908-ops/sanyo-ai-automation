# Sanyo Yusoki Vietnam — People Assets

## Purpose

Define reusable character references.

## Character Metadata

Each reusable character should have:

- Character ID
- Approximate age group
- Role
- Clothing
- Hair
- Appearance
- Personality
- Typical environment
- Approved reference image

## Consistency

When a character is reused:

- Face identity should remain stable
- Clothing should remain stable unless intentionally changed
- Approximate age should remain stable
- Body proportions should remain stable
- Character role should remain consistent

## Naming Convention

PERSON_[ROLE]_[ID]_V[VERSION]

Example:

PERSON_HOMEOWNER_F01_V01
