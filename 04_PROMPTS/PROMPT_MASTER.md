# Sanyo Yusoki Vietnam — Prompt Master

## 1. Purpose

Prompt Master is the central prompt orchestration layer for the Sanyo AI Automation system.

It transforms:

Customer Problem
→ Customer Insight
→ Content Direction
→ Video Brief
→ VEO 3 Prompt

## 2. Prompt Architecture

Every production prompt should be assembled from modular components:

- Brand Context
- Customer Context
- Content Objective
- Hook
- Story
- Product Context
- Visual Direction
- Camera Direction
- Character Direction
- Scene Direction
- Audio Direction
- CTA
- Negative Constraints

## 3. Core Principle

A prompt must serve the customer story first.

The elevator is the solution inside the story,
not the reason for creating the story.

## 4. Output Principles

Prompts must be:

- Clear
- Specific
- Consistent
- Visually executable
- Customer relevant
- Brand consistent
- Safe
- Non-aggressive

## 5. Production Flow

Input
→ Select prompt modules
→ Assemble prompt
→ Apply VEO 3 rules
→ Quality check
→ Production
